## ⚡ Overview
This repository contains the complete source code for my V4 interactive cybersecurity portfolio. 
The underlying system engine utilizes a custom WebP 72-frame sequence preloader to deliver a flawless **60FPS scroll-locked background animation**—completely bypassing the latency, stuttering, and mobile-browser limitations of traditional HTML5 `<video>` elements.

## 🛠️ System Architecture
- **Frontend Core:** Pure HTML5 structure utilizing semantic `<section>` blocks and layered `<canvas>` rendering.
- **Glassmorphism Engine:** CSS3 frosted-glass `bento-grid` overlays synchronized with responsive, mobile-first flexbox and CSS Grid designs.
- **Render Engine:** Vanilla JavaScript utilizing a `requestAnimationFrame` loop that mathematically calculates frame-indexes natively against `window.scrollY` vectors for instant reverse/forward playback parity.
